# 서산시지부 현수막 지정게시대 — 멀티페이지(.html 분리) 시연용 웹앱

`../index.html` 단일 파일 프로토타입을 **실제로 분리된 17개 `.html` 페이지**로 다시 구축한 결과물입니다.
원본 `index.html`·`README.md`·검증 스크립트는 그대로 보존되어 있고, 이 폴더만 새로 만든 것입니다.

- 단일 파일: `../index.html` (약 7.06MB — .ai/.eps/.pdf 5종이 base64로 내장)
- 멀티페이지: 페이지 1장은 8~31KB, 공통 `assets/app.js`(약 458KB)·`assets/style.css`(약 92KB),
  대용량 원본 파일은 `files/`에 실제 파일로 두고 **내려받을 때만** 전송

## 실행

- 그냥 열기: `index.html`을 브라우저로 연다(`file://`에서도 상대 경로·다운로드 동작 확인).
- 서버로 열기: `python3 -m http.server 8000` 후 `http://localhost:8000/index.html`.

## 추첨 가산점 (2026-11-22 부여자별 최종 합산)

- 가산점은 **직책자 본인에게 주는 것이 아니라, 직책자가 대상에 부여하는 권한**입니다.
  접수자 본인의 직책으로 자동 가산하지 않습니다.
- **시한임박 현수막**과 **협회 등록 회원사** 모두 **기본 0%**(가중치 1.00배)입니다.
- **부여자 각각이 자기 권한 한도까지 부여하고, 부여된 가산점은 최종 합산됩니다.**
  한 부여자가 다른 부여자의 몫을 덮어쓰지 못하며, 같은 부여자가 다시 부여하면 그 부여자의
  몫만 갱신되고 해제하면 그 몫만 빠집니다(나머지 부여자 % 유지).
- 부여 한도(한 사람당): **지부장 최대 +5% · 수석부지부장 +3% · 현장실무원 +3% · 사무실무원 +2%**
  (사무국장·감사·일반 회원은 부여 불가, 총괄 관리자는 지부장과 같은 5% 한도, 한도 초과는 거부).
  네 직책이 모두 부여하면 **최대 +13%**까지 합산됩니다.
- 예: 지부장 +5% + 사무실무원 +2% = **합산 +7% → 가중치 1.07배** / 4인 모두 = **+13% → 1.13배**.
- 시한임박 **인정 범위는 차차주까지**(게첨 시작일부터 2주 뒤 주 일요일, 20일 이내)입니다.
- 추첨 가중치 = `1.00 + (시한임박 부여자 합산 % + 협회 등록 회원사 부여자 합산 %) / 100`.
- 부여 내역(직책·성명·%·시각)은 대상에 `urgentGrants[]`·`assocGrants[]` 배열로 부여자별 1항목씩
  쌓이고, 화면에는 부여자별 칩과 `합계 +N%`가 함께 표시되며 감사 로그·추첨 로그에 세부 내역이 남습니다.
- 옛 단일 구조(`urgentGrant`·`assocGrant`)로 저장된 데이터는 첫 실행 때 자동으로 배열로 옮겨집니다.

## 참고

- 시연용 프로토타입입니다. 실제 접수·추첨·입금·입고와 연결되지 않습니다.

  SHA-256과 바이트 수를 원본 표기와 대조해 검증했습니다.
